0) ENG OSON START (terminal kodsiz — ikki marta bosish)
-------------------------------------------------------
1. setup.bat   — bir marta bosib o'rnatadi (Python + Node paketlar)
2. run.bat     — HAMMA xizmatni YASHIRIN (oynasiz) rejimda ochadi:
     - Ollama + backend + web UI fon rejimida ishlaydi (terminal YO'Q),
     - DESKTOP app oynasi avtomatik ochiladi (native oyna).
       Desktop hali qurilmagan bo'lsa — brauzer ochiladi
       (http://localhost:1420) fallback sifatida.
   Qo'shimcha:  run.bat menu   -> interaktiv menyu (desktop/web/server only)
                run.bat build  -> desktop appni bir marta qurib oladi
                run.bat stop   -> barcha xizmatni to'xtatadi
3. stop.bat    — xuddi shunday: barcha xizmatlarni to'xtatadi (1420/8765/11434)
Log fayllar:   logs/vite.log, Igris_brain/logs/server.log, Igris_brain/logs/ollama.log,
               Igris_brain/logs/watchdog.log (watchdog)

Watchdog (auto-restart): run.bat bilan avtomatik ishga tushadi
(Igris_brain/monitor/watchdog.py). Alohida jarayon bo'lib, har ~4 soniyada
backend'ni (8765) va Ollama'ni (11434) tekshiradi; qulab tushsa yoki javob
bermay qolsa — o'zi qayta ishga tushiradi. Shuning uchun "birdan offline
bo'lib qolish" holati yo'qoladi (brain ~16 soniyada avtomatik tiklanadi).
Restart'lar exponential backoff bilan cheklangan (10 daqiqada max 8) va
UI'dan qilingan restart'ga xalaqit bermaydi (marker handshake).
Holat: Igris_brain/logs/watchdog.json (Settings → Services'da ko'rinadi).
Quyidagi barcha komandalar shu fayllarga muqobil — qo'lda boshqarish
uchun kerak bo'lsa.

4) WEB-AI-BRIDGE (real Chrome brauzer tool'lari)
-------------------------------------------------
MCP serveri Igris_brain/tools/mcp_servers.json orqali avtomatik ulanadi
(brain server ishga tushganda). Alohida ishga tushirish shart emas.

Sozlash (Igris_brain/tools/mcp_servers.json -> "web_ai_bridge"):
  - WAB_CDP_ENABLED: "true"  -> REAL Chrome + mr.wtin profili (tavsiya etiladi)
  - WAB_CDP_URL: "http://127.0.0.1:9222" -> CDP endpoint
  - WAB_CDP_PORT: "9222"
  - WAB_CHROME_USER_DATA: "C:/Users/user/AppData/Local/Google/Chrome/User Data"
  - WAB_CHROME_PROFILE: "Profile 1"  -> mr.wtin profili (twinm6142@gmail.com)
  - WAB_HEADLESS: "false" (CDP rejimda ahamiyatsiz — Chrome real oynasi ko'rinadi)
  - WAB_BROWSER_CHANNEL: "chrome" (legacy rejim uchun; CDP rejimda ishlatilmaydi)
  - cwd -> web-ai-bridge/server papkasi (loyiha ko'chsa yangilang)

CDP rejim: bridge real Google Chrome'ni mr.wtin profili bilan ochadi
(avtomatik --remote-debugging-port=9222), so'ng unga ulanadi. Bridge
Chromeni o'ldirmaydi — faqat ulanishni yopadi.

Chrome 136+ dagi cheklov: --remote-debugging-port faqat standart bo'lmagan
data-dir'da ochiladi. Bridge buni avtomatik hal qiladi: real "User Data"
papkasiga JUNCTION (bog'lanish) yaratadi:
  ...\Google\Chrome-IGRIS-CDP  ->  ...\Google\Chrome\User Data
Chrome shu yo'l bilan ochiladi — debug port ishlaydi, real mr.wtin profili
jonli qoladi. Agar "Chrome-IGRIS-CDP" nomli papka allaqachon boshqa narsa
bo'lsa, uni o'chiring (link qayta yaratiladi).

Chrome profili bitta instance'da ochiq bo'lishi mumkin: agar mr.wtin
Chrome'i ochiq bo'lsa, uning barcha oynalarini yoping va qayta urinib
ko'ring.
