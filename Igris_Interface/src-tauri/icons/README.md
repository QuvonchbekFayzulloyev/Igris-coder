# Icons Directory

Place your app icons here:
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (macOS)
- icon.ico (Windows)

You can generate icons using:
- https://icon.kitchen/
- https://www.figma.com/
- Or use any image editor

For now, you can remove the icon references from tauri.conf.json
or create placeholder PNGs with any image tool.
